# 联网搜索

输入框下方的“联网搜索”默认开启，可随时关闭，选择会自动保存。无需填写额外服务地址或搜索密钥，API 接入和订阅账号使用相同流程。

开启时，助手先用当前所选模型判断是否需要外部资料；解释和总结已有视频片段通常不搜索，明确要求查资料、核实事实或查询最新信息时会尝试搜索。这会增加一次简短的模型调用；关闭后省去这次判断，也不向搜索引擎发送请求。

## 检索与回答

1. 搜索规划只接收用户问题和截至当前播放位置的少量文字，不包含视频标题、视频链接或画面。
2. 最多生成两个简短查询，扩展仅向搜索服务发送这些关键词，不携带模型 API Key、订阅凭证或浏览器 Cookie。
3. 优先查询 Bing 的公开搜索页面，失败或没有相关结果时尝试 DuckDuckGo；仍不可用时，使用 Wikipedia 的标准搜索 API 补充百科知识。百科结果不能替代最新新闻或实时数据。
4. 搜索结果经过链接校验、去重和基本相关性筛选，最多保留六条。搜索查询在扩展后台内存缓存五分钟，最多缓存二十项。
5. 将取得的标题、链接和摘要交给当前模型，再结合已播放视频内容回答。不会自动打开搜索结果网页，也不声称已阅读全文。引用外部信息时要求使用真实返回的来源链接。

公共搜索服务可能限流、要求验证或变更页面。助手不会处理验证码或绕过验证；未取得结果时会提示本次搜索不可用，继续根据已有视频内容回答，并要求模型说明最新信息未核实。

## 视频范围和来源

整段视频仍然识别并完整缓存。搜索规划和最终模型请求都过滤播放位置之后的文本；不检索视频结局或后续事件，外部资料仅用于补充已播放部分的知识。模型必须区分网页知识与视频里已经出现的内容。

回答中的来源链接可以点击；回答下方的“联网搜索”折叠区域列出实际取得的搜索结果。启用历史保存时，这些结果随问答保存在本机，导出 Markdown 时也会带上链接。

- [MediaWiki 搜索 API](https://www.mediawiki.org/wiki/API:Search)

运行 `node scripts/test-web-search.mjs` 可验证搜索规划、API/订阅调用、备用检索、搜索失败、关闭开关、查询缓存、播放范围限制、凭证隔离和链接渲染。完整扩展检查使用 `npm run validate` 和 `npm test`。
